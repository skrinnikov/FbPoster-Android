# FB Poster

CLI-приложение для парсинга RSS/Atom лент и публикации постов в группы Facebook через Graph API.

## Возможности
- Парсинг нескольких лент, дедупликация, сортировка по дате
- Публикация в несколько групп
- Хранилище SQLite для отметки уже опубликованных пунктов
- Повторный запуск в цикле с интервалом

## Установка
1. Установите Python 3.10+
2. Создайте виртуальное окружение и активируйте его:
   - PowerShell:
     ```bash
     python -m venv .venv
     .venv\\Scripts\\Activate.ps1
     ```
3. Установите зависимости и пакет:
   ```bash
   pip install -e .
   ```

## Настройка
Создайте `.env` по образцу `.env.example` и заполните:

- `FB_USER_ACCESS_TOKEN` — долгоживущий токен с правами `publish_to_groups` и `groups_access_member_info`.
- `FB_GROUP_IDS` — список ID групп через запятую.
- `FEED_URLS` — список URL лент через запятую.
- Остальные параметры по желанию.

Важно: доступ к публикации в группы требует соответствующих прав приложения и одобрения Facebook. Получение токена и прав лежит на пользователе.

## Использование
Запуск единичного прогона:
```bash
fb-poster --max-posts 5
```

Непрерывный режим с интервалом из `POST_INTERVAL_SECONDS`:
```bash
fb-poster --loop
```

## Скрипт
В `scripts/run.ps1` можно поместить удобную команду запуска.

## Предупреждения
- Соблюдайте правила Facebook и местные законы по рассылкам.
- Тестируйте в тестовых группах.
